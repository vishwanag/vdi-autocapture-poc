🎯 One-time setup (no coding)

This POC uses a model that actually recognises each side of the car and auto-captures only when the correct side is in view.

Train your free model in ~10 min:

  1. Open Teachable Machine → Image Project
  2. Create 4 classes, name them exactly: Front, Left, Right, Rear
  3. For each class, record ~40–60 photos of that side of the car (different angles/distances)
  4. Click Train Model → then Export Model → TensorFlow.js → Upload
  5. Copy the “Your sharable link” URL and paste it below 👇

Tip: class names in Teachable Machine must match Front / Left / Right / Rear (any capitalisation).
